# OpenCode Python SDK

## Overview

The OpenCode Python SDK (`opencode-ai`) is the official Python client for the [OpenCode](https://opencode.ai) API. It provides both synchronous and asynchronous clients with full type annotations via Pydantic models and TypedDicts.

### Installation

```bash
pip install --pre opencode-ai
```

The latest pre-release version is `0.1.0a36`. The SDK requires Python 3.8 or later and is published on PyPI at [opencode-ai](https://pypi.org/project/opencode-ai/).

### Source

The SDK is hosted at [github.com/anomalyco/opencode-sdk-python](https://github.com/anomalyco/opencode-sdk-python) and is generated by [Stainless](https://stainless.com) from the OpenAPI specification of the OpenCode API.

### Critical Note

This SDK is an **HTTP client only**. It does not include plugin support or event hooks. Unlike the JavaScript/TypeScript SDK (`@opencode-ai/sdk`), there is no equivalent `createOpencode()` function that spawns a server process. You must connect to a running OpenCode server manually.

## Client Types

### Sync Client

```python
from opencode_ai import Opencode

client = Opencode(
    base_url="http://localhost:8000",
    api_key="optional-api-key"
)
```

### Async Client

```python
from opencode_ai import AsyncOpencode

client = AsyncOpencode(
    base_url="http://localhost:8000",
    api_key="optional-api-key"
)
```

### Type Safety

All request and response models are defined as Pydantic models with additional TypedDict variants for flexible input. This enables IDE autocompletion and runtime validation out of the box.

## API Coverage

### Sessions

Full session lifecycle management:

| Method | Description |
|---|---|
| `client.session.create()` | Create a new session |
| `client.session.list()` | List all sessions |
| `client.session.init()` | Initialize session (analyze and create AGENTS.md) |
| `client.session.delete()` | Delete a session |
| `client.session.chat()` | Send a chat message to a session |
| `client.session.abort()` | Abort an in-progress request |
| `client.session.revert()` | Revert a session to a previous state |
| `client.session.unrevert()` | Restore reverted messages |
| `client.session.share()` | Generate a share link for a session |
| `client.session.unshare()` | Remove share link |
| `client.session.summarize()` | Summarize session context |
| `client.session.messages()` | List messages in the session |

### Files

| Method | Description |
|---|---|
| `client.file.read()` | Read a file from the workspace |
| `client.file.status()` | Get file status metadata |

### Find

| Method | Description |
|---|---|
| `client.find.text()` | Text search across the workspace |
| `client.find.files()` | Search for files by pattern |
| `client.find.symbols()` | Find symbol definitions |

### Config

| Method | Description |
|---|---|
| `client.config.get()` | Retrieve current OpenCode configuration |

### App

| Method | Description |
|---|---|
| `client.app.get()` | Get app-level information (version, modes, providers) |
| `client.app.init()` | Initialize the app and create AGENTS.md |
| `client.app.log()` | Write a log entry |
| `client.app.modes()` | List available modes |
| `client.app.providers()` | List providers and default models |

### TUI

| Method | Description |
|---|---|
| `client.tui.append_prompt()` | Append text to the terminal UI prompt |
| `client.tui.open_help()` | Open the help dialog |

### Events

The SDK supports Server-Sent Events (SSE) for streaming event data. Use `client.event.list()` to receive real-time events from the server:

```python
from opencode_ai import Opencode

client = Opencode(
    base_url="http://localhost:8000",
)

stream = client.event.list()
for event in stream:
    print(event)
```

The async client uses the same interface:

```python
from opencode_ai import AsyncOpencode

client = AsyncOpencode(
    base_url="http://localhost:8000",
)

stream = await client.event.list()
async for event in stream:
    print(event)
```

## Key Differences from JS/TS SDK

| Aspect | Python SDK | JS/TS SDK |
|---|---|---|
| **Client creation** | `Opencode(base_url=...)` | `createOpencode()` (spawns server) |
| **Plugin system** | Not supported | `@opencode-ai/plugin` with event hooks |
| **Event hooks** | None | `tool.execute.before`, `tool.execute.after`, etc. |
| **Server management** | Manual (connect to existing server) | Automatic (spawns managed server) |
| **Type system** | Pydantic models + TypedDicts | TypeScript types |

The Python SDK is strictly a client library. It does not provide:

- A server or daemon implementation
- Plugin registration or lifecycle hooks
- The `@opencode-ai/plugin` equivalent for extending OpenCode behavior
- Automatic workspace or connection management

To use the Python SDK, you must point it at an already-running OpenCode instance, typically started via the OpenCode CLI or a managed deployment.
