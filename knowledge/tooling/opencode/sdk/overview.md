# OpenCode JS/TS SDK

The `@opencode-ai/sdk` package provides a programmatic TypeScript interface to the OpenCode editor. It enables agents, scripts, and external tools to interact with OpenCode sessions, files, configuration, and editor UI without requiring a browser or IDE plugin.

## API Reference

All methods use the `{ path, body, query }` object pattern generated by `@hey-api/openapi-ts`. None accept positional arguments.
