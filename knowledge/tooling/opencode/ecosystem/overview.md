# OpenCode Ecosystem

## Overview

The OpenCode ecosystem extends the core agent runtime through community-contributed plugins, projects, and agents. These cover authentication, tool execution, editor integration, deployment workflows, context management, and full-scale application frontends.

Two primary aggregation points exist:

- **awesome-opencode** — a community-curated GitHub repository listing plugins, projects, agents, and resources.
- **opencode.cafe** — a community hub for sharing and discovering OpenCode extensions.

## Contents

This topic is split into atomic files for focused reference:

- [plugins.md](./plugins.md) — Catalogue of community plugins organized by category (auth, sandbox, editing, context, security, shell, web, notifications, workflow, monitoring, formatting, suites, integrations).
- [projects.md](./projects.md) — Community projects built on or extending OpenCode, including editor plugins, SDK providers, and application frontends.
- [agents.md](./agents.md) — Community agents and agent suites distributed as standalone packages.
