# Keep a Changelog 2.0.0

Knowledge notes on the [Keep a Changelog](https://keepachangelog.com/en/2.0.0/) standard for maintaining changelog files in software projects. "Clearly document the evolution of your projects."

## Notes

- [spec.md](spec.md) — Specification: what a changelog is, guiding principles, and core requirements
- [sections.md](sections.md) — Defined change types: Added, Changed, Deprecated, Removed, Fixed, Security; Unreleased section; section ordering; yanked releases
- [format.md](format.md) — File format conventions: reverse chronology, Markdown headings, date and version formatting, link references
- [best-practices.md](best-practices.md) — Best practices for maintaining an effective changelog
