# SDK Types

All TypeScript types are generated from the OpenAPI specification and re-exported:

```ts
import type { Session, Message, Part } from "@opencode-ai/sdk";
```

## Key Types

### `Session`

A conversation session with metadata, model config, and message history.

| Field | Type | Description |
|---|---|---|
| `id` | `string` | Unique session identifier |
| `projectID` | `string` | The project this session belongs to |
| `directory` | `string` | Working directory for the session |
| `parentID?` | `string` | Parent session ID for child/thread sessions |
| `summary?` | `{ additions, deletions, files, diffs? }` | Git diff summary of changes made in the session |
| `share?` | `{ url: string }` | Share URL if the session is shared |
| `title` | `string` | Session title |
| `version` | `string` | OpenCode version used |
| `time` | `{ created, updated, compacting? }` | Timestamps (unix ms) |
| `revert?` | `{ messageID, partID?, snapshot?, diff? }` | Revert/undo state |

### `Message`

A single message within a session. This is a discriminated union of `UserMessage` and `AssistantMessage`.

| Discriminant | Variant | Role |
|---|---|---|
| `role: "user"` | `UserMessage` | Message sent by the user |
| `role: "assistant"` | `AssistantMessage` | Message generated by the AI |

#### `UserMessage`

| Field | Type | Description |
|---|---|---|
| `id` | `string` | Unique message identifier |
| `sessionID` | `string` | Parent session |
| `role` | `"user"` | Discriminant |
| `time` | `{ created: number }` | Creation timestamp |
| `summary?` | `{ title?, body?, diffs }` | Optional user-provided summary |
| `agent` | `string` | Agent that handled the message |
| `model` | `{ providerID, modelID }` | Model used when sending |
| `system?` | `string` | System prompt override |
| `tools?` | `{ [key: string]: boolean }` | Tool enablement flags |

#### `AssistantMessage`

| Field | Type | Description |
|---|---|---|
| `id` | `string` | Unique message identifier |
| `sessionID` | `string` | Parent session |
| `role` | `"assistant"` | Discriminant |
| `time` | `{ created, completed? }` | Creation and completion timestamps |
| `error?` | `ProviderAuthError \| UnknownError \| MessageOutputLengthError \| MessageAbortedError \| ApiError` | Error if the response failed |
| `parentID` | `string` | The message this responds to |
| `modelID` | `string` | Model used for generation |
| `providerID` | `string` | Provider used |
| `mode` | `string` | Agent mode at time of response |
| `path` | `{ cwd, root }` | Working and root directories |
| `summary?` | `boolean` | Whether the message is a summary |
| `cost` | `number` | Cost of the response in USD |
| `tokens` | `{ input, output, reasoning, cache }` | Token usage breakdown |
| `finish?` | `string` | Finish reason |

### `Part`

A content part within a message. A discriminated union of 12 variants identified by the `type` field:

| Type Variant | Key Fields | Description |
|---|---|---|
| `"text"` (`TextPart`) | `id`, `text`, `synthetic?`, `ignored?`, `time?` | Plain text content |
| `"reasoning"` (`ReasoningPart`) | `id`, `text`, `time` | Chain-of-thought reasoning text |
| `"file"` (`FilePart`) | `id`, `mime`, `filename?`, `url`, `source?` | File attachment (image, PDF, etc.) |
| `"tool"` (`ToolPart`) | `id`, `callID`, `tool`, `state` | Tool invocation (see below) |
| `"step-start"` (`StepStartPart`) | `id`, `snapshot?` | Marks the beginning of a thinking step |
| `"step-finish"` (`StepFinishPart`) | `id`, `reason`, `snapshot?`, `cost`, `tokens` | Marks the end of a thinking step |
| `"snapshot"` (`SnapshotPart`) | `id`, `snapshot` | Session state snapshot for undo |
| `"patch"` (`PatchPart`) | `id`, `hash`, `files` | File patch applied to the workspace |
| `"agent"` (`AgentPart`) | `id`, `name`, `source?` | Agent handoff or switch |
| `"retry"` (`RetryPart`) | `id`, `attempt`, `error`, `time` | Automatic retry of a failed step |
| `"compaction"` (`CompactionPart`) | `id`, `auto` | Session compaction boundary |
| `"subtask"` (`SubtaskPart`) | `id`, `prompt`, `description`, `agent` | Subtask delegation |

All part types share three base fields: `id`, `sessionID`, `messageID`.

### `ToolPart`

A tool invocation part within a message. Identified by `type: "tool"`.

| Field | Type | Description |
|---|---|---|
| `id` | `string` | Part identifier |
| `sessionID` | `string` | Parent session |
| `messageID` | `string` | Parent message |
| `type` | `"tool"` | Discriminant |
| `callID` | `string` | Unique call identifier for correlating invocations |
| `tool` | `string` | Name of the tool being invoked |
| `state` | `ToolState` | Current state (pending, running, completed, error) |
| `metadata?` | `object` | Arbitrary metadata |

`ToolState` is itself a discriminated union:

| Status | Fields | Description |
|---|---|---|
| `"pending"` | `status`, `input`, `raw` | Tool queued and waiting |
| `"running"` | `status`, `input`, `title?`, `metadata?`, `time` | Tool currently executing |
| `"completed"` | `status`, `input`, `output`, `title`, `metadata`, `time`, `attachments?` | Tool finished successfully |
| `"error"` | `status`, `input`, `error`, `metadata?`, `time` | Tool failed with an error |

### `Agent`

Agent metadata as exposed by the API.

| Field | Type | Description |
|---|---|---|
| `name` | `string` | Agent name |
| `description?` | `string` | Description of when to use this agent |
| `mode` | `"subagent" \| "primary" \| "all"` | Agent role |
| `builtIn` | `boolean` | Whether this is a built-in agent |
| `topP?` | `number` | Nucleus sampling parameter |
| `temperature?` | `number` | Generation temperature |
| `color?` | `string` | Hex color code (e.g. `#FF5733`) |
| `permission` | `{ edit, bash, webfetch?, doom_loop?, external_directory? }` | Tool permission presets |
| `model?` | `{ modelID, providerID }` | Override model |
| `prompt?` | `string` | System prompt override |
| `tools` | `{ [key: string]: boolean }` | Tool enablement flags |
| `options` | `{ [key: string]: unknown }` | Additional options |
| `maxSteps?` | `number` | Max agentic iterations before forcing text response |

### `Project`

Project workspace information.

| Field | Type | Description |
|---|---|---|
| `id` | `string` | Unique project identifier |
| `worktree` | `string` | Absolute path to the project root |
| `vcsDir?` | `string` | VCS directory (e.g. `.git`) |
| `vcs?` | `"git"` | Version control system type |
| `time` | `{ created, initialized? }` | Timestamps (unix ms) |

### `Config`

OpenCode configuration object. This is the parsed form of `opencode.json` with all defaults resolved.

| Category | Key Fields | Description |
|---|---|---|
| Display | `theme?`, `username?`, `layout?` | UI appearance |
| Model | `model?`, `small_model?` | Default and light-weight models |
| Agents | `agent?` | Per-agent configuration (`plan`, `build`, `general`, `explore`, etc.) |
| Providers | `provider?` | Custom provider definitions and model overrides |
| MCP | `mcp?` | Model Context Protocol server configs (local/remote) |
| Permissions | `permission?` | Tool permission defaults (edit, bash, webfetch, etc.) |
| Keybinds | `keybinds?` | Custom keybinding overrides |
| TUI | `tui?` | Terminal UI settings (scroll speed, diff style) |
| Share | `share?` | Sharing mode (manual, auto, disabled) |
| LSP | `lsp?` | Language server configurations |
| Formatter | `formatter?` | Code formatter configurations |
| Experimental | `experimental?` | Feature flags (telemetry, batch tool, etc.) |

### `Provider`

LLM provider definition as exposed by the API.

| Field | Type | Description |
|---|---|---|
| `id` | `string` | Provider identifier (e.g. `"anthropic"`) |
| `name` | `string` | Human-readable name |
| `source` | `"env" \| "config" \| "custom" \| "api"` | How the provider was loaded |
| `env` | `string[]` | Environment variable names for credentials |
| `key?` | `string` | Current API key (masked) |
| `options` | `{ [key: string]: unknown }` | Provider options |
| `models` | `{ [key: string]: Model }` | Available models keyed by model ID |

Each `Model` object includes: `id`, `providerID`, `name`, `capabilities` (temperature, reasoning, attachment, toolcall, input/output modalities), `cost` (input, output, cache), `limit` (context, output tokens), `status`.

### `Todo`

A session todo item tracked within the workspace.

| Field | Type | Description |
|---|---|---|
| `content` | `string` | Brief description of the task |
| `status` | `string` | Current status: `pending`, `in_progress`, `completed`, or `cancelled` |
| `priority` | `string` | Priority level: `high`, `medium`, or `low` |
| `id` | `string` | Unique identifier for the todo item |
