# OpenCode SDKs

Documentation for the official OpenCode SDKs — the TypeScript/JavaScript SDK (`@opencode-ai/sdk`) and the Python SDK (`opencode-ai`).

## Files

| File | Description |
|---|---|
| `overview.md` | Index of all SDK reference files |
| `installation.md` | Installing the SDK and its foundational dependencies |
| `client-creation.md` | Creating a client with `createOpencode()` or `createOpencodeClient()` |
| `types.md` | All exported TypeScript types (Session, Message, Part, etc.) |
| `error-handling.md` | Error handling modes and structured output validation failures |
| `structured-output.md` | Requesting typed JSON responses via `json_schema` format |
| `api-sessions.md` | Session CRUD, prompt, shell, diff, fork, and related methods |
| `api-files.md` | File search and read/status APIs |
| `api-tui.md` | TUI methods for controlling the editor UI programmatically |
| `api-misc.md` | Health, logging, agents, project, path, config, auth, and events APIs |
| `python.md` | OpenCode Python SDK — sync/async clients |
