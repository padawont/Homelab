# Changelog

Simple change records for this repository. Each file is a dated markdown entry recording what changed and why.

## Naming

`{date}-{title}-changelog.md` — e.g., `2026-07-14-restructure-configs-changelog.md`

## Format

Free-form markdown. No frontmatter or special structure — just document what changed and why.

See `AGENTS.md` for full rules.
