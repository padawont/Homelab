# Docker / Containerized CI

Generate a Dockerfile that replicates the Devbox environment:

```bash
devbox generate dockerfile
```

Flags:
- `--root-user`: Use root as the container user (installs Nix in single-user mode)
- `-f, --force`: Overwrite existing files

This Dockerfile can be used to build CI images that include the exact toolchain, or to produce production images from the same environment definition.

```dockerfile
# Generated by `devbox generate dockerfile`
# Build: docker build -t my-app .
```
