# OpenCode MCP Servers

Reference documentation for the Model Context Protocol (MCP) server integration in OpenCode: local and remote server configuration, OAuth authentication, tool management, and usage examples.

## Files

- `overview.md` — Index of all MCP notes with brief descriptions and links
- `concepts.md` — What MCP is, local vs remote, caveats, MCP vs custom tools
- `configuration.md` — MCP server configuration in `opencode.json`
- `local-servers.md` — Local subprocess MCP servers
- `remote-servers.md` — Remote HTTP MCP servers
- `oauth.md` — OAuth 2.0 authentication flow
- `tool-management.md` — Tool discovery, enable/disable, per-agent scoping
- `examples.md` — Ready-to-use config examples (Sentry, Context7, Grep)
