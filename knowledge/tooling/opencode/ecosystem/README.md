# OpenCode Ecosystem

Community plugins, projects, and agents extending the OpenCode runtime. Covers authentication, sandboxing, code editing, context management, workflow orchestration, monitoring, editor integrations, and full-stack frontends.

## Files

- `overview.md` — Index of the ecosystem topic with links to atomic files
- `plugins.md` — Catalogue of community plugins organized by category (auth, sandbox, editing, context, security, shell, web, notifications, workflow, monitoring, formatting, suites, integrations)
- `projects.md` — Community projects built on or extending OpenCode
- `agents.md` — Community agents and agent suites distributed as standalone packages
