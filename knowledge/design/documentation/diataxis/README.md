# Diataxis Documentation Framework

A systematic approach to technical documentation authoring, based on four distinct modes of communication aligned to user needs.

Diataxis (from Ancient Greek δῐᾰ́τᾰξῐς: *dia* — "across", *taxis* — "arrangement") is a lightweight, pragmatic framework for thinking about and creating documentation. It solves problems related to documentation *content* (what to write), *style* (how to write it), and *architecture* (how to organise it).
