# SDK Miscellaneous APIs

All methods use the `{ path, body, query }` object pattern generated by `@hey-api/openapi-ts`. None accept positional arguments.

## Global

### `client.global.health()`

Check server health and version.

```ts
const health = await client.global.health();
console.log(health.data.version);
// { healthy: true, version: "0.45.0" }
```

## App

### `client.app.log({ body })`

Emit a structured log entry.

```ts
await client.app.log({
  body: {
    service: "my-script",
    level: "info",
    message: "Operation completed",
  },
});
```

| Field | Type | Description |
|---|---|---|
| `body.service` | `string` | Service or component name |
| `body.level` | `"debug" \| "info" \| "warn" \| "error"` | Log severity |
| `body.message` | `string` | Log message |
| `body.extra` | `Record<string, unknown>` | Structured metadata (optional) |

### `client.app.agents()`

List all registered agents (both built-in and custom).

```ts
const agents = await client.app.agents();
// [{ name: "Build", mode: "primary", hidden: false }, ...]
```

## Project

### `client.project.list()`

List all projects in the workspace.

```ts
const projects = await client.project.list();
// [{ name: "my-app", path: "/home/user/my-app" }]
```

### `client.project.current()`

Get the currently active project.

```ts
const current = await client.project.current();
// { name: "my-app", path: "/home/user/my-app" }
```

## Path

### `client.path.get()`

Get the current working directory and related path information.

```ts
const pathInfo = await client.path.get();
// { cwd: "/home/user/my-app", home: "/home/user" }
```

## Config

### `client.config.get()`

Retrieve the current OpenCode configuration.

```ts
const config = await client.config.get();
// { agent: { ... }, model: { ... }, tools: { ... } }
```

### `client.config.providers()`

List configured LLM providers and their default models.

```ts
const { providers, default: defaults } = await client.config.providers();
// providers: [{ name: "anthropic", defaultModel: "claude-sonnet-4-20250514" }]
```

## Auth

### `client.auth.set({ path, body })`

Set authentication credentials for a provider.

```ts
await client.auth.set({
  path: { id: "anthropic" },
  body: { type: "api", key: "sk-ant-..." },
});
```

| Field | Type | Description |
|---|---|---|
| `path.id` | `string` | Provider ID |
| `body.type` | `"api" \| "oauth" \| "wellknown"` | Authentication type |
| `body.key` | `string` | API key (optional, for api type) |
| `body.token` | `string` | Token (optional, for wellknown type) |

## Events

### `client.event.subscribe()`

Subscribe to the server-sent events (SSE) stream for real-time notifications.

```ts
const events = await client.event.subscribe();

for await (const event of events.stream) {
  console.log("Event:", event.type, event.properties);
}
```

Events provide real-time notifications for session state changes, file modifications, and other server-side activity.
