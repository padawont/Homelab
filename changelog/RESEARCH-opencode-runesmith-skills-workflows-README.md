# RuneSmith Skills — Workflows

This folder contains research analyses for RuneSmith workflow skills — skills that guide agents through multi-step processes (issue decomposition, PR generation, changelog management, testing, commit writing, documentation architecture).

## Files

| File | Description |
|---|---|
| [issue-to-plan.md](issue-to-plan.md) | Decompose GitHub issues into structured implementation plans |
| [pr-packager.md](pr-packager.md) | Generate PR descriptions from git commits (backward workflow) |
| [changelog-manager.md](changelog-manager.md) | Generate and maintain CHANGELOG.md following Keep a Changelog 2.0.0 |
| [test-helper-run.md](test-helper-run.md) | Run test suites and collect results |
| [test-helper-diagnose.md](test-helper-diagnose.md) | Interpret test failures and suggest fixes |
| [rs-doc-architect.md](rs-doc-architect.md) | Diataxis-based documentation audit and restructuring plan |
| [rs-commit-writer.md](rs-commit-writer.md) | Generate Conventional Commit messages from staged diff |
| [rs-pr-writer.md](rs-pr-writer.md) | Generate PR body from issue/spec (forward workflow) |
