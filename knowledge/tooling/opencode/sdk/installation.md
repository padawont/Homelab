# SDK Installation

The `@opencode-ai/sdk` package provides a programmatic TypeScript interface to the OpenCode editor. It enables agents, scripts, and external tools to interact with OpenCode sessions, files, configuration, and editor UI without requiring a browser or IDE plugin.

```bash
npm install @opencode-ai/sdk
```

## Foundations

The SDK is built on two foundations:

- **`@hey-api/openapi-ts`** — auto-generates a typed HTTP client from the OpenCode OpenAPI specification. All API shapes (`Session`, `Message`, `Part`, etc.) are derived from the spec and surfaced as TypeScript types. Every SDK method uses the `{ path, body, query }` object pattern generated by the OpenAPI client.
- **`cross-spawn`** — cross-platform process spawning for shell commands and subprocess management.

The SDK is framework-agnostic plain TypeScript. There are no React, Express, or Fastify dependencies. It works in any Node.js or Bun environment.

## Prerequisites

- **Node.js ≥ 22** or **Bun ≥ 1.x** — the SDK targets modern ESM runtimes
- **TypeScript ≥ 5.x** (optional) — full type definitions included

## Verify Installation

```bash
npm list @opencode-ai/sdk
# @opencode-ai/sdk@1.16.2

node -e "import('@opencode-ai/sdk').then(m => console.log(Object.keys(m)))"
```
